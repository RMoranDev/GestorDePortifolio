# Gestor de Projetos

Sistema desenvolvido em **Python** como projeto da disciplina de **Raciocínio Computacional** da **PUCPR**.

## Sobre o projeto

Aplicação de linha de comando para gerenciamento de projetos, permitindo cadastrar, listar, atualizar e excluir projetos, além de acompanhar seu histórico e consultar estatísticas.

Os dados são armazenados localmente em um arquivo **JSON**.

## Funcionalidades

* Cadastrar projetos
* Listar projetos
* Adicionar histórico e anotações
* Marcar projetos como concluídos
* Excluir projetos
* Consultar estatísticas
* Armazenar dados em JSON

## Tecnologias

* Python
* JSON

## Como executar

1. Tenha o **Python 3** instalado.
2. Clone este repositório.
3. Execute:

```bash
python main.py
```
